# 🍔 Swiggy Dashboard Analysis

## 📌 Project Overview
This project is an interactive **Swiggy Food Delivery Dashboard** created using **Microsoft Excel**. The dashboard analyzes food order data across different cities, restaurants, categories, ratings, and pricing trends.

The goal of this project is to perform **data analysis and visualization** to gain insights into customer preferences, restaurant performance, and sales metrics.

---

# 📊 Dashboard Features

- KPI Cards for:
  - Total Revenue
  - Average Rating
  - Total Rating Count
  - Total Orders
  - Average Order Value (AOV)

- Interactive Analysis of:
  - Restaurant Performance
  - Food Categories
  - City-wise Orders
  - Price Analysis
  - Rating Trends
  - Veg vs Non-Veg Food Distribution

- Pivot Tables & Data Cleaning
- Dynamic Excel Dashboard
- Business Insights Generation

# 📂 Dataset Information
